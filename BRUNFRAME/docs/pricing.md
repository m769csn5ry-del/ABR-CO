# Tarification

**Statut : grille NON figée.** Les valeurs ci-dessous sont des hypothèses de travail (H) posées par le conseil du 22/10/2026 ; elles se valident par des ventes réelles (voir `assumptions.md`, A8).

## Méthode
Construire le prix à partir de : expérience, marché ciblé, temps de production mesuré, complexité, coûts logiciels, maintenance, révisions, charges, risque, valeur perçue. Ne pas fixer un prix en copiant les concurrents.
