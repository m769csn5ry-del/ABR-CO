# Clientèle cible

Petites marques e-commerce et commerces qui veulent améliorer leur présence digitale.

| Marché | Profils |
|---|---|
| Mode | marques indépendantes, boutiques, créateurs, accessoires |
| Bijoux | créateurs indépendants, marques artisanales, boutiques spécialisées, collections premium |
| Cosmétiques | petites marques de soins, beauté, produits naturels, marques émergentes |
| Décoration | objets décoratifs, accessoires maison, marques de design, boutiques spécialisées |

## Prospect idéal
Plusieurs de ces critères : produits commercialisables · marque identifiable · site existant perfectible · visuels insuffisants · présence active sur les réseaux · besoin visible · capacité à payer · décideur joignable. **Besoin visible ≠ intention d'achat.**

## Cible d'entrée recommandée (D-001/D-006, H)
Boutiques indépendantes bijoux/mode de Strasbourg, par contact direct (visite + message), pour un pack de visuels ; la déco sert de vitrine à l'offre site via la démo Maison Habitée.
