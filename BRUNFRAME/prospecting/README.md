# Prospection

- Canaux : visite et contact direct (local), LinkedIn, Instagram, e-mail, réseau, recommandations.
- **Aucun faux prospect, aucun faux historique.** Le CRM démarre vide (`templates/crm-prospects.csv`, en-têtes seulement).
- **Données personnelles de prospects : jamais dans le dépôt.** Les copier dans `prospecting/private/`, ignoré par git (`BRUNFRAME/.gitignore`), ou dans un outil externe.
- Messages personnalisés sur un problème précis observé ; pas de message générique.
- Règles de la prospection B2B par message (RGPD/CNIL) : **non vérifiées** (assumptions A19) — à lire avant la première campagne.
